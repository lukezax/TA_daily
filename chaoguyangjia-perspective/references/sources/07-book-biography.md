## 三、新增核心内容（Skill 中未覆盖的）

### 3.1 控制回撤三条铁律

**铁律一：能赚1块时只赚7毛，留3毛济世**
- 弱水三千只取一瓢
- 对市场保持敬畏和感恩
- 不贪到极致

**铁律二：决不能把盈利的做成亏损的**
- 从大幅盈利→中等盈利→小幅盈利→亏损的心理滑坡链条
- 拉高出货是常用招数，需无脑执行此铁律
- 这条是对"反脆弱资金管理"的具体操作化

**铁律三：仓位提前计划，知行合一**
- 盘中受大盘起落影响，情绪必然波动
- "计划不够细致 = 看似有计划实则没计划"
- 仓位配比 + 应对策略 = 完整预案

### 3.2 复盘三层框架

```
大局定仓位 → 热点情绪定板块 → 根据板块定个股
```

**第一层：大局定仓位**
- 可操作区间 → 仓位50%-80%
- 不可操作区间 → 仓位0%-30%
- 100%仓位的时机一年不超过6次

**第二层：热点情绪定板块**
- 市场热点板块（政策驱动、资金聚集）
- 自己熟悉的板块（信息优势）
- 建议选取3-5个板块做复盘

**第三层：根据板块定个股**
- 按涨停先后顺序，翻看技术图、分时图、量能
- 识别龙头、中军、情绪标
- 看龙虎榜了解资金动向

**"素养"检验标准**（能回答以下问题 = 素养到位）：
1. 板块的逻辑是什么？
2. 板块由哪些个股构成？（至少10只）
3. 哪些是活跃股/低估值/叠加题材/次新/大盘/小盘？
4. 每一波走势的领涨股是谁？
5. 今天行情由谁发动，跟风的是哪几个？

### 3.3 集合竞价（关键15分钟）

- 集合竞价 = 判断情绪强弱与导向
- 好的竞价模式：筹码均匀，后期有抢筹动作（分时图向上走）
- 标杆股竞价走弱 → 板块冲高计划泡汤 → 第一时间止损/止盈
- 这是短线选手最紧张、最忙碌的交易时间

### 3.4 热点操作四步法

1. **预判热点性质**：主流 / 次主流 / 非主流？
2. **试错轻仓买入**：预判 → 试错 → 确认 → 加仓
3. **主流可重仓**：龙头或后发品种均可，仓位稍重无妨
4. **非主流轻仓**：隔日卖出，赚快钱

### 3.5 交易体系三个操作逻辑

**逻辑一：坚决打有准备之战**
- 前一天做好计划（目标股、介入区间）
- 盘中不被直线拉升干扰

**逻辑二：好的策略应有预案**
- 大盘涨 → 组合大幅涨
- 大盘跌 → 小跌或不跌
- "大脑盘中判断绝对没有盘后清醒"

**逻辑三：好的策略应有事后评估**
- 每天总结操作（成功/失败）
- 用本子记录 → 强化正确策略 → 排除情绪化操作

### 3.6 曾犯过的错

**错误1：动不动满仓**
- 原因：场内不能控制情绪，盈利头脑发热 or 亏损想扳回
- 满仓 = 除了上涨无路可走 = 被动

**错误2：吃着碗里看着锅里**
- 持有的不涨 → 看别的股快速拉升 → 慌不择路冲进去
- 一个错误的结束 = 另一个错误的开始
- 最致命：看涨速榜选股（非计划内）

### 3.7 知行合一

> "知道的和做到的差太多了，所以知行合一四个字足够很多人修行几年的了。"

- 盘中判断不如盘后清醒 → 靠计划而非临场决策
- 制定的策略越详细越好，甚至精确到介入区间
- "还不够痛"是知行不合一的根本原因

### 3.8 写给新手的忠告

> "没有建立完整的交易体系之前，没有足够资金解决后顾之忧之前，没有详细深入了解职业炒手之前，没有取得家人完全支持之前，不要轻言去专职炒股。"

- 这是一个付出不一定有回报的行业
- 这是一个努力不一定有结果的行业
- 成功者极少而失败者满街都是
- 贸然进入 = 可能是深渊
