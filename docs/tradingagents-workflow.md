# TradingAgents 多 Agent 工作流文档

## 一、整体执行流程

```
┌─────────────────────────────────────────────────────────────────┐
│                        分析阶段（并行数据采集）                      │
├─────────────────────────────────────────────────────────────────┤
│  市场分析师 → 社媒分析师 → 新闻分析师 → 基本面分析师               │
│  (技术面)     (情绪面)     (事件面)     (财务面)                   │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                        研究辩论阶段                                │
├─────────────────────────────────────────────────────────────────┤
│  看涨研究员 ←→ 看跌研究员（多轮辩论，由 max_debate_rounds 控制）    │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                        决策阶段                                    │
├─────────────────────────────────────────────────────────────────┤
│  研究经理（综合辩论结果）→ 交易员（制定交易计划）                    │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                        风控辩论阶段                                │
├─────────────────────────────────────────────────────────────────┤
│  激进分析师 ←→ 保守分析师 ←→ 中性分析师（多轮，max_risk_discuss_rounds）│
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                        最终裁决                                    │
├─────────────────────────────────────────────────────────────────┤
│  风控经理（最终投资决策）                                           │
└─────────────────────────────────────────────────────────────────┘
```

---

## 二、各 Agent 详细说明

### 1. 市场分析师（Market Analyst）

**文件**: `tradingagents/agents/analysts/market_analyst.py`
**角色**: 技术面分析

**绑定工具**: `get_stock_market_data_unified`（自动识别股票类型，获取K线+技术指标）

**输入**: `trade_date`, `company_of_interest`
**输出**: `market_report`

**系统提示词**（核心部分）:
```
您是一位专业的AI助手，与其他分析师协作进行股票分析。
使用提供的工具获取和分析数据。

输出格式要求（必须严格遵守）：

# **{company_name}（{ticker}）技术分析报告**

## 一、股票基本信息
- 公司名称、股票代码、所属市场
- 当前价格：[从工具数据中获取]
- 涨跌幅、成交量

## 二、技术指标分析
### 1. 移动平均线（MA）分析
### 2. MACD指标分析
### 3. RSI相对强弱指标
### 4. 布林带（BOLL）分析

## 三、趋势判断
## 四、支撑位与阻力位
## 五、成交量分析
## 六、综合技术评估
## 七、交易建议
```

### 2. 基本面分析师（Fundamentals Analyst）

**文件**: `tradingagents/agents/analysts/fundamentals_analyst.py`
**角色**: 财务数据分析和估值

**绑定工具**: `get_stock_fundamentals_unified`

**输入**: `trade_date`, `company_of_interest`（固定10天数据窗口）
**输出**: `fundamentals_report`

**系统提示词**（核心部分）:
```
你是一位专业的股票基本面分析师。
⚠️ 绝对强制要求：你必须调用工具获取真实数据！不允许任何假设或编造！

任务：分析{company_name}（股票代码：{ticker}，{market_name}）

🔴 立即调用 get_stock_fundamentals_unified 工具
参数：ticker='{ticker}', start_date='{start_date}', end_date='{current_date}'

📊 分析要求：
- 基于真实数据进行深度基本面分析
- 计算并提供合理价位区间（使用{currency_symbol}）
- 分析当前股价是否被低估或高估
- 提供基于基本面的目标价位建议
- 包含PE、PB、PEG等估值指标分析
- 结合市场特点进行分析

🌍 语言和货币要求：
- 所有分析内容必须使用中文
- 投资建议必须使用中文：买入、持有、卖出
- 货币单位使用：{currency_name}（{currency_symbol}）
```

### 3. 新闻分析师（News Analyst）

**文件**: `tradingagents/agents/analysts/news_analyst.py`
**角色**: 新闻事件影响分析

**绑定工具**: `get_stock_news_unified`（统一新闻工具，自动识别股票类型）

**输入**: `trade_date`, `company_of_interest`
**输出**: `news_report`

**系统提示词**（核心部分）:
```
您是一位专业的金融新闻分析师，负责分析最新新闻对股票投资的影响。

分析重点：
1. 新闻时效性评估（优先分析15-30分钟内的新闻）
2. 新闻对股价的潜在影响（正面/负面/中性）
3. 新闻可信度和来源权威性评估
4. 短期（1-3天）和中期（1-2周）影响预判
5. 关键信息提取和投资建议

✅ 强制执行步骤：
1. 您的第一个动作必须是调用 get_stock_news_unified 工具
2. 该工具会自动识别股票类型并获取相应新闻
3. 只有在成功获取新闻数据后，才能开始分析

⚠️ 如果您不调用工具，您的回答将被视为无效并被拒绝。
```

**特殊处理**: 对 DashScope/DeepSeek/Zhipu 模型强制预获取新闻数据（绕过工具调用问题）

### 4. 社媒情绪分析师（Social Media Analyst）

**文件**: `tradingagents/agents/analysts/social_media_analyst.py`
**角色**: 投资者情绪分析

**绑定工具**: `get_stock_sentiment_unified`（基于东方财富新闻做情绪分析）

**输入**: `trade_date`, `company_of_interest`
**输出**: `sentiment_report`

**系统提示词**（核心部分）:
```
您是一位专业的中国市场社交媒体和投资情绪分析师。

您的主要职责包括：
1. 分析中国主要财经平台的投资者情绪（如雪球、东方财富股吧等）
2. 监控财经媒体和新闻对股票的报道倾向
3. 识别影响股价的热点事件和市场传言
4. 评估散户与机构投资者的观点差异
5. 分析政策变化对投资者情绪的影响

📊 情绪影响分析要求：
- 量化投资者情绪强度（乐观/悲观程度）和情绪变化趋势
- 评估情绪变化对短期市场反应的影响（1-5天）
- 提供基于情绪分析的市场预期和投资建议

💰 必须包含：
- 情绪指数评分（1-10分）
- 预期价格波动幅度
- 基于情绪的交易时机建议

🔴 严格禁止事项：
- 绝对禁止编造或假设社交媒体讨论内容
- 绝对禁止使用错误的公司名称（必须严格使用工具返回的公司名称）
- 如果工具返回"无法获取"或"数据不可用"，必须如实报告
- 分析必须100%基于工具返回的真实数据
- 如果数据不足，直接说明"数据不足，无法进行完整的情绪分析"
```

**Ground Truth 注入**:
```
📌 关键事实（不可更改）：
- 公司名称：{company_name}
- 股票代码：{ticker}
⚠️ 严禁使用其他公司名称。
```

**输出**: `investment_debate_state.bull_history`

```
📌 关键事实（来自实时行情工具验证，不可更改）：

- 股票代码：{ticker}
- 当前价格：¥{correct_price}

你是一位看涨分析师，负责为股票 {correct_name}（股票代码：{ticker}）的投资建立强有力的论证。

你的目标是提出合理的论证，强调增长潜力、竞争优势和正面指标。
```

**绑定工具**: 无（纯推理）

**输出**: `investment_plan`

**系统提示词**（核心部分）:
```
📌 关键事实（来自实时行情工具验证，不可更改）：
- 公司名称：{correct_name}
- 股票代码：{ticker}
- 当前价格：¥{correct_price}
⚠️ 严禁使用其他公司名称或价格数据。

作为投资组合经理和辩论主持人，您的职责是批判性地评估这轮辩论并做出明确决策：
支持看跌分析师、看涨分析师，或者仅在有强有力理由时选择持有。

您的建议——买入、卖出或持有——必须明确且可操作。
避免仅仅因为双方都有有效观点就默认选择持有。

为交易员制定详细的投资计划，包括：

   - 基准目标价
   - 乐观目标价
4. 时间框架：1个月/3个月/6个月预期
5. 风险管理：止损位和仓位建议

🚨 强制要求：必须提供具体的目标价位数值，不允许说"无法确定"
```

### 8. 交易员（Trader）

**文件**: `tradingagents/agents/trader/trader.py`
**角色**: 制定最终交易决策

**绑定工具**: 无（纯推理）

**输入**: `investment_plan` + 所有分析师报告 + 历史记忆
**输出**: `trader_investment_plan`

**系统提示词**（核心部分）:
```
您是一位专业的交易员，负责分析市场数据并做出投资决策。

📌 关键事实（来自实时行情工具验证，不可更改）：
- 公司名称：{correct_name}
- 股票代码：{company_name}
- 当前价格：¥{correct_price}
请确保你的分析严格基于以上事实。

🔴 严格要求：
- 绝对禁止使用错误的公司名称或混淆不同的股票
- 所有分析必须基于提供的真实数据
- 必须提供具体的目标价位，不允许设置为null或空值

请在您的分析中包含以下关键信息：
1. 投资建议: 明确的买入/持有/卖出决策
2. 目标价位: 基于分析的合理目标价格 - 🚨 强制要求提供具体数值
3. 置信度: 对决策的信心程度(0-1之间)
4. 风险评分: 投资风险等级(0-1之间)
5. 详细推理: 支持决策的具体理由

🎯 目标价位计算指导：
- 基于基本面分析中的估值数据（P/E、P/B、DCF等）
- 参考技术分析的支撑位和阻力位
- 考虑行业平均估值水平
- 结合市场情绪和新闻影响

请用中文撰写，以'最终交易建议: **买入/持有/卖出**'结束。
```

**价格提取**: 使用 `extract_price_with_fallback()`（增强正则 + 智兔API + MongoDB fallback）

### 12. 风控经理（Risk Manager / Risk Judge）

**文件**: `tradingagents/agents/managers/risk_manager.py`
**角色**: 最终风险裁决

**绑定工具**: 无（纯推理）

**输入**: 风控辩论历史 + 交易员决策 + 所有分析师报告
**输出**: `final_trade_decision`

**系统提示词**（核心部分）:
```
📌 关键事实（来自实时行情工具验证，不可更改）：
- 公司名称：{correct_name}
- 股票代码：{company_name}
- 当前价格：¥{correct_price}
⚠️ 严禁使用其他公司名称或价格数据。

作为风险管理委员会主席和辩论主持人，您的目标是评估三位风险分析师
——激进、中性和安全/保守——之间的辩论，并确定交易员的最佳行动方案。

您的决策必须产生明确的建议：买入、卖出或持有。

决策指导原则：
1. 总结关键论点：提取每位分析师的最强观点
2. 提供理由：用辩论中的直接引用和反驳论点支持您的建议
3. 完善交易员计划：从交易员的原始计划开始，根据分析师的见解进行调整

最终输出必须包含：
- 明确的行动建议（买入/持有/卖出）
- 置信度（0-1）
- 风险评分（0-1）
- 目标价位
- 风险缓解策略
```

## 三、数据流总结

| 阶段 | Agent | 读取 | 写入 |
|------|-------|------|------|
| 分析 | 市场分析师 | trade_date, ticker | market_report |
| 分析 | 社媒分析师 | trade_date, ticker | sentiment_report |
| 分析 | 新闻分析师 | trade_date, ticker | news_report |
| 分析 | 基本面分析师 | trade_date, ticker | fundamentals_report |
| 辩论 | 看涨研究员 | 4份报告 + 辩论历史 | bull_history |
| 辩论 | 看跌研究员 | 4份报告 + 辩论历史 | bear_history |
| 决策 | 研究经理 | 4份报告 + 辩论历史 + 记忆 | investment_plan |
| 决策 | 交易员 | investment_plan + 4份报告 + 记忆 | trader_investment_plan |
| 风控 | 激进分析师 | trader_plan + 4份报告 + 风控历史 | risky_history |
| 风控 | 保守分析师 | trader_plan + 4份报告 + 风控历史 | safe_history |
| 风控 | 中性分析师 | trader_plan + 4份报告 + 风控历史 | neutral_history |
| 裁决 | 风控经理 | trader_plan + 风控历史 + 4份报告 | final_trade_decision |

## 四、关键配置参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `max_debate_rounds` | 1 | 看涨/看跌辩论轮数 |
| `max_risk_discuss_rounds` | 1 | 风控辩论轮数 |
| `memory_enabled` | false | 是否启用历史记忆 |
| `online_tools` | true | 是否使用在线工具 |
| `selected_analysts` | ["market","social","news","fundamentals"] | 启用的分析师 |
| `deep_think_llm` | - | 深度思考模型（用于辩论/决策） |
| `quick_think_llm` | - | 快速思考模型（用于分析师） |

## 五、防幻觉机制

1. **Ground Truth 注入**: 所有非工具调用的 Agent（研究员、交易员、风控）都在 prompt 中注入从 market_report 提取的正确公司名称和价格
2. **价格 Fallback**: `extract_price_with_fallback()` — 增强正则匹配 8 种格式 + 智兔 API + MongoDB
3. **强制工具调用**: 基本面分析师有机制强制 LLM 调用工具获取真实数据
4. **报告校验器**: `report_validator.py` — TDD 风格校验公司名称/价格/代码，错误时要求 LLM 重新生成（最多 3 次）
5. **社媒反编造**: 情绪分析师 prompt 明确禁止编造，工具返回真实新闻数据
