## 二、核心心法（原文精华）

### 1. 情绪周期论

> "买入倾向的推理，大多来自赚钱效应，卖出倾向的推理，大多来自亏钱效应。"

> "热点来自题材，持续性来自赚钱效应！"

- 市场短期情绪有规律可循，长期无法预料
- 赚钱效应扩散 = 参与信号；亏钱效应扩散 = 回避信号
- 涨停所在 = 情绪所在 = 人气所在

### 2. 赢面-仓位决策体系

| 赢面 | 操作 |
|------|------|
| <60% | 观望 |
| 60%-70% | 小仓出击 |
| 70%-80% | 中仓出击 |
| >80% | 大仓出击 |
| >90% | 满仓（需同时满足：胜率90%+，上涨空间30%-50%，下跌空间3%-5%） |

> "所有身家全部压在一个股票上时，通常我要求极高的赢面，一年也就4-5次。"

### 3. 大局观

> "做的是短线，但是看的是更大的局。"

大局观 = 政策面 + 技术面 + 资金面 + 基本面 + 人气面的综合共振

- 不拘泥于个股，关注板块整体走势
- 关注领涨/领跌品种的后续表现
- 政策顶层设计驱动的题材（如碳中和）= 世纪性大题材

### 4. 知行合一

> "知道的和做到的差太多了，所以知行合一四个字足够很多人修行几年的了。"

- 盘中判断不如盘后清醒 → 靠计划而非临场决策
- 制定的策略越详细越好，甚至精确到介入区间
- "还不够痛"是知行不合一的根本原因

### 5. 概率主义

> "做对的操作，盈亏的事情交给概率。"

> "完善了交易体系，输赢交给概率，看不准的时候割肉就可以了，不必拘泥！"

## 三、控制回撤三条铁律

### 铁律一：能赚1块时只赚7毛，留3毛济世

- 弱水三千只取一瓢
- 对市场保持敬畏和感恩

### 铁律二：决不能把盈利的做成亏损的

- 从大幅盈利到中等盈利 → 心理不平衡
- 从中等盈利到小幅盈利 → 更无法接受
- 但拉高出货是常用招数 → 需无脑执行此铁律

### 铁律三：仓位提前计划，知行合一

- 盘中受大盘起落影响，情绪必然波动
- 计划不够细致 = 看似有计划实则没计划
- 仓位配比 + 应对策略 = 完整预案

## 四、复盘框架

### 从大到小的三层过滤

```
大局定仓位 → 热点情绪定板块 → 根据板块定个股
```

**第一层：大局定仓位**
- 可操作区间 → 仓位50%-80%
- 不可操作区间 → 仓位0%-30%
- 100%仓位的时机一年不超过6次

**第二层：热点情绪定板块**
- 市场热点板块（政策驱动、资金聚集）
- 自己熟悉的板块（信息优势）
- 建议选取3-5个板块做复盘

**第三层：根据板块定个股**
- 按涨停先后顺序，翻看技术图、分时图、量能
- 识别龙头、中军、情绪标
- 看龙虎榜了解资金动向

### "素养"的检验标准

能回答以下问题 = 素养到位：
1. 板块的逻辑是什么？
2. 板块由哪些个股构成？（至少10只）
3. 哪些是活跃股/低估值/叠加题材/次新/大盘/小盘？
4. 每一波走势的领涨股是谁？
5. 今天行情由谁发动，跟风的是哪几个？

## 五、热点操作四步法

1. **预判热点性质**：主流 / 次主流 / 非主流？
2. **试错轻仓买入**：预判 → 试错 → 确认 → 加仓
3. **主流可重仓**：龙头或后发品种均可，仓位稍重无妨
4. **非主流轻仓**：隔日卖出，赚快钱

### 龙头 vs 跟风的选择逻辑

- 买龙头 ≠ 胆大，而是龙头有更高溢价且尚未反映
- 买跟风 = 龙头赚钱效应十足，跟风品种尚处低位，风险较小
- 关键：观察龙头和跟风品种间的**套利关系**

## 六、交易体系构建

### 体系的第一步：买卖逻辑

> "你如果定义短线，那就要有短线买入的逻辑，也得有卖出的逻辑。"

买入逻辑 = 大局所定 + 消息驱动 + 情绪所在 + 技术判断 → 测算盈亏概率 → 决定仓位和策略

卖出逻辑 = 上述因素是否还存在 → 看好则持股，不看好则卖出

### 三个操作逻辑

**逻辑一：坚决打有准备之战**
- 前一天做好计划（目标股、介入区间）
- 盘中不被直线拉升干扰

**逻辑二：好的策略应有预案**
- 大盘涨 → 组合大幅涨
- 大盘跌 → 小跌或不跌
- 大脑盘中判断绝对没有盘后清醒

**逻辑三：好的策略应有事后评估**
- 每天总结操作（成功/失败）
- 用本子记录 → 强化正确策略 → 排除情绪化操作

## 七、关于技术分析的辩证看法

> "技术派有个陷阱：从后往前看，都是对的。"

- 必须学技术 → 协助筛选目标、识破主力意图、规避明显问题
- 但技术不是全部 → 需结合大局观 + 情绪把握 + 回撤控制
- 同样的技术形态 → 完全不同的走势 → 因为缺少情绪维度

## 八、集合竞价（关键15分钟）

- 集合竞价 = 判断情绪强弱与导向
- 好的竞价模式：筹码均匀，后期有抢筹动作（分时图向上走）
- 标杆股竞价走弱 → 板块冲高计划泡汤 → 第一时间止损/止盈
- 这是短线选手最紧张、最忙碌的交易时间

---

## 九、曾经犯过的错

**错误1：动不动满仓**
- 原因：场内不能控制情绪，盈利头脑发热 or 亏损想扳回
- 满仓 = 除了上涨无路可走 = 被动

**错误2：吃着碗里看着锅里**
- 持有的不涨 → 看别的股快速拉升 → 慌不择路冲进去
- 一个错误的结束 = 另一个错误的开始
- 最致命：看涨速榜选股（非计划内）

## 十、写给新手的忠告

> "没有建立完整的交易体系之前，没有足够资金解决后顾之忧之前，没有详细深入了解职业炒手之前，没有取得家人完全支持之前，不要轻言去专职炒股。"

- 这是一个付出不一定有回报的行业
- 这是一个努力不一定有结果的行业
- 成功者极少而失败者满街都是
- 贸然进入 = 可能是深渊

### 复利目标参考

| 频率 | 收益率 | 一年净值 |
|------|--------|---------|
| 每月 | 5% | 180% |
| 每周 | 2% | 280% |
| 每月 | 10% | 314% |

> "给自己目标就是每月5%-10%，达到了就很知足。"
