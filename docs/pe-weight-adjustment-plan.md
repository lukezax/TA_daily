# PE 权重调整方案

**问题**: 90% 的分析报告把 PE 偏高作为主要风险因素，导致绝大多数筛选通过的股票被判"卖出"或"持有"，与 B1/B2 波段策略的实际使用场景不匹配。

**根因**: Prompt 中没有明确交易时间框架，LLM 默认按中长期价值投资逻辑判断。

---

## 修改方案

### 文件1: `tradingagents/agents/analysts/fundamentals_analyst.py`

**位置**: `create_fundamentals_analyst` 函数中的 `system_message` 变量（约第170行）

**当前 prompt（问题部分）**:
```
"- 包含PE、PB、PEG等估值指标分析"
"- 分析当前股价是否被低估或高估"
```

**改为**:
```python
"📊 分析要求："
"- 基于真实数据进行深度基本面分析"
f"- 计算并提供合理价位区间（使用{market_info['currency_name']}{market_info['currency_symbol']}）"
"- 包含PE、PB等估值指标的客观数据展示"
"- 提供基于基本面的目标价位建议"
"- 结合市场特点进行分析"
"⏰ 交易时间框架说明（重要）："
"- 本系统服务于中短期波段交易（持仓周期1-3周）"
"- PE估值分析仅作为参考背景信息，不应作为否决买入的主因"
"- 重点关注：公司是否有基本面硬伤（亏损、退市风险、财务造假）"
"- PE高低的判断标准："
"  * PE > 500 或为负值：⚠️ 可能存在基本面危机，需重点提示"
"  * PE 50-500：正常波动范围，对波段交易影响有限，客观陈述即可"
"  * PE < 50：估值合理或偏低，可作为加分项"
"- 不要因为PE=60或PE=80就判断为'估值严重偏高'——对成长股和周期股这是常见区间"
```

---

### 文件2: `tradingagents/agents/trader/trader.py`

**位置**: `trader_node` 函数中的 system content（约第85行 messages 列表的 system 部分）

**当前 prompt（问题部分）**:
```
"🎯 目标价位计算指导："
"- 基于基本面分析中的估值数据（P/E、P/B、DCF等）"
"- 参考技术分析的支撑位和阻力位"
"- 考虑行业平均估值水平"
"- 结合市场情绪和新闻影响"
"- 即使市场情绪过热，也要基于合理估值给出目标价"
```

**改为**:
```
"⏰ 交易框架（重要）："
"- 本系统服务于中短期波段交易，典型持仓周期1-3周"
"- 买入决策主要依据：技术面信号强度、资金流向、支撑压力位、短期催化剂"
"- PE估值不是波段交易的核心决策因素（除非PE>500暗示基本面危机）"
""
"🎯 目标价位计算指导："
"- 首要参考：技术分析的支撑位和阻力位（布林带、均线压力位）"
"- 次要参考：近期波动幅度（ATR）、前高前低"
"- 辅助参考：基本面估值区间（仅用于判断上方空间）"
"- 结合市场情绪和资金面情况"
"- 不要因为PE偏高就大幅压低目标价——波段交易的目标是捕捉技术性反弹"
```

---

### 文件3（可选）: `tradingagents/agents/researchers/bear_researcher.py`

看空研究员天然倾向于找风险因素，PE 高是它最容易抓的把柄。可以在其 prompt 中加一句约束：

```
"⏰ 注意：本系统服务于1-3周的波段交易。请聚焦短期内可能导致下跌的实质性风险（如业绩暴雷、减持公告、行业政策利空），而非中长期估值偏高本身。PE 在 50-200 范围内对短期走势影响有限。"
```

---

## 预期效果

| 指标 | 改前 | 改后 |
|------|------|------|
| "PE偏高"导致判卖出的比例 | ~50% | ~10%（仅PE>500的极端情况） |
| 最终建议为"买入"的比例 | ~10% | ~30-40%（技术面信号强的应该买入） |
| 报告中仍包含PE数据 | ✅ | ✅（作为参考信息展示，不作为决策核心） |
| 基本面硬伤检测（亏损/退市风险） | 有 | 有（保留） |

---

## 不改的部分

- 基本面数据获取逻辑不变（PE/PB/ROE 照常获取和展示）
- 风控辩论节点不改（让它自由辩论，但 trader 最终决策时参照新框架）
- 市场分析师(market_analyst)不改（技术面分析跟 PE 无关）
