# 纠错反馈记录

当策略研究员的 insight 或 recommendation 被人工确认为错误/无效时，记录到此目录。
研究员在下次执行时会读取最近的 corrections 作为上下文，避免重复犯错。

## 记录格式

```markdown
# 纠错: [原始insight标题]

- **原始结论**: ...
- **实际情况**: ...
- **错误原因**: (数据不足/逻辑推导错误/外部条件变化/...)
- **教训**: ...
- **日期**: YYYY-MM-DD
```

## 使用方式

人工发现研究员的结论有误时，在此目录新建一个 .md 文件记录。
研究员会在 `read_recent_context()` 中读取最近7天的 corrections。
